# Reference data

Lookup files loaded into `silver.ref_*` tables by `databricks/notebooks/02_reference.py` and read by the `transform/`
code. Tests in `tests/test_reference_data.py` check their columns, allowed values and consistency.

| File | What it holds | Made how |
|---|---|---|
| `skills.csv` | skills with aliases, exclusions and case rules | by hand (Phase 2, reviewed in the 2.11 hand-check) |
| `locations.csv` | exact raw location values used by sources ("USA", "EMEA", "Remote", "Deutschland"…) | by hand |
| `countries.csv` | every country: ISO code, English name, region | generated by `scripts/build_geo_reference.py` |
| `cities.csv` | place names (lowercased, with alternate spellings such as "münchen" and "munich") → city and country; a shared name goes to the European place, then the most populous | generated by `scripts/build_geo_reference.py` |
| `industries.csv` | each source's categories or tags → our industries (Jobicy's 22 plus Hardware & Electronics, Research & Science, Engineering & Manufacturing, Logistics & Supply Chain) | by hand, from the Phase 2b profiling |
| `job_types.csv` | each source's job types → Full-Time, Part-Time, Contract, Internship, Temporary | by hand, from the Phase 2b profiling |
| `levels.csv` | each source's level values → our seniority levels (a fallback when the title has no level) | by hand, from the Phase 2b profiling |

In the three mapping files, matching ignores case, and an **empty target means "reviewed, deliberately not mapped"**:
contract-only job types ("Unbefristeter Arbeitsvertrag"), tags too broad to name one industry ("IT", "Consulting"),
and Jobicy's unreliable levels ("Director", "Any"). `tests/fixtures/source_vocabulary.json` lists the values each
source used when profiled, and the tests require every one of them to be classified.

`countries.csv` and `cities.csv` contain data from [GeoNames](https://www.geonames.org), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Generated on 2026-10-21 from `countryInfo.txt` and
`cities1000.zip` (places with more than 1,000 inhabitants). Our regions and a few country names (Türkiye, Czechia,
Netherlands) are applied by the script. To refresh, run the script, review the diff and commit.
